# Play Dice

A Flutter app that rolls two dice. If the total is 10 or more, it shows a happy image and "You Win". Otherwise it shows a sad image and "You Lose".

## Description

- Press **roll** to throw two dice and update the total and the image.
- Press **reset** to put both dice back to 1, the total to 2, and the sad image.


## Run

    flutter pub get
    flutter run
